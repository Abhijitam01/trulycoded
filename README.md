# Truly Coded - Premium B2B Agency Website_

A sophisticated, professional website for Truly Coded - a premium B2B agency specializing in brand identity and web development for seed and Series A tech startups.

## 🎯 Project Overview

This is a modern, responsive website built with a focus on **professional elegance** and **performance**. The design follows the Jords.co.uk aesthetic - clean, minimal, and sophisticated, emphasizing typography and content over flashy effects.

### ✨ Key Features

- **Professional Design System** - Refined color palette with sophisticated blue accents
- **Premium Typography** - Bricolage Grotesque font with optimized hierarchy
- **Minimal Loading Experience** - Clean, elegant page loader
- **Responsive Design** - Mobile-first approach with touch-optimized interactions
- **Performance Optimized** - Fast loading with lazy loading and code splitting
- **Accessibility Focused** - WCAG 2.1 AA compliant with proper focus states
- **PWA Ready** - Progressive Web App capabilities with offline support

## 🛠️ Development Setup

### Prerequisites

- **Node.js** (v18 or higher) - [Install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
- **npm** (comes with Node.js)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/Abhijitam01/parivartanx-reimagined.git

# Navigate to project directory
cd parivartanx-reimagined

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173`

### Available Scripts

## 🎨 Design System

### Color Palette
- **Primary Blue**: `hsl(217, 50%, 48%)` - Professional, sophisticated
- **Background**: Cream/Beige in light mode, True black in dark mode

### Typography
- **Font**: Bricolage Grotesque (Variable)
- **Hierarchy**: Optimized font weights and sizes
- **Spacing**: Consistent line heights and letter spacing

### Components
- **Cards**: Subtle shadows, rounded corners (8px radius)
- **Buttons**: Professional styling with hover states
- **Animations**: Subtle, purposeful transitions (200ms duration)
